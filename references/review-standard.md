# 复盘内容标准

沿用五模块、错题六字段；全部题目另有简短考点与定位路径。篇幅按需要调整，不凑页数。题型判定只读取 [question-types.md](question-types.md) 中本篇出现的章节；定位与计时按 [locating-and-timing.md](locating-and-timing.md) 处理，方法来源与习惯训练见 [method-guides.md](method-guides.md)。

## 先核验材料

- 对照完整原文、题目、作答和可靠答案，核实题号、题型、答案与成绩。颜色依用户说明或可核实批改解释，不套用其他材料的约定。
- 保留必要选项、字数、否定及限定；证据注明位置。材料缺失、截图不清或答案冲突时标明未核验，不补猜、不计入确定成绩。
- 分开可观察事实与个人原因。未记录的用时、顺序和当时想法写“未记录”；未高亮不等于漏读。答对只能确认结果，不能反推其方法有效或已经熟练。

## 固定五模块

### 01 本篇概况

列材料、成绩、错题号、已知用时和各题型正确数／题数；指出优先处理的一至两个问题。有过程依据才认定有效做法。单篇不能推出整体能力或雅思分数。

计时注明整套、单篇或题组，记录实际用时、已知预算与来源；有预算才计算差额。超时后成绩与限时内完成数分开。总时间只能证明是否超预算，不能据此断言定位慢；有记录才进一步区分寻找、理解证据、比较选项和重复回查。

用户要求全文复盘时，用 `overview.passage_map` 做一张紧凑的 **全文回查图**：每段一行，字段为段落、内容作用、回查用途。读完全部段落再写，包含没有直接出题的段落，区分主张、原因、对照、例子或结论；用途可以是“为后文对照提供背景”，不强行给无题段分配题号。这是复盘后建立的检索图，不是考生初读前已掌握的答案地图，也不要求考场逐段写摘要。单段通常一句即够，不放长引文或逐段翻译。

### 02 逐题复盘

先给出 **每题定位与提速**，覆盖全部题号，包括正确题和待核对题。三列为“题号｜从哪里找｜确认与省时动作”：中列依次给题干入口、实际扫读路线、核实的段句或范围；右列用短标签区分具体考点、确定条件和独立的“省时”动作。`test_point` 描述本题关系或限制，不把“信息匹配／同义替换”当成充分考点。入口与路径须体现题干怎样变成寻找目标、原文怎样换一种说法；确认条件说明答案满足了什么。省时指出复用位置、合并处理或停止扩读，必要时补本题卡住后的处理。共用策略放在模块04，不逐题重复。不能只写答案段号，也不能把未知答案词放到检索入口。

答对题通常到速查表为止，但同样要看得出“考什么—怎样找—如何确认”，不能只列答案。答对但耗时长、有过程记录的题可作简短方法点评，必要时沿用六字段；猜对或低把握需用户记录支持，不凭结果推断。缺原文或无法核实位置时保留“待核对＋缺少什么”，不编造考点与路径。NOT GIVEN 标相关核查范围与缺失关系，不能给虚假的“答案句”。

定位表后，每道错题使用六字段；必要的低把握题也可沿用。无错题时保留模块和完整定位表，再说明无错题。

1. **作答结果**：题号、用户答案、正确答案、题型。
2. **题目要求**：完整题干及必要选项、字数要求；用普通中文保留主体、范围、时间、否定、比较或因果等条件。
3. **正确证据**：位置、最短充分引文及必要句意；把题干条件与原文表达对应起来，用一两句说明如何得出答案，不仅给引文或译文。说明改写在当前语境中如何成立，不把词对当成通用等号。省略不能删掉决定答案的关系或限定。Not Given 写核查范围与缺失关系，可不附引文。
4. **答案对比**：说明原答案缺少或错配的条件。两个候选相关时承认共同点，再指出原文主体、关系、对象或限定的具体差异；不能只说“更直接／更完整”，也不能以段落主旨替代指定信息。
5. **错因判断**：先写可确认的答案缺口，再写个人原因的状态。用 `cause.stage` 写与缺口对应的 **优先检查步骤**，如“读题：是否保留比较双方与维度”“核对：是否把目的当成实际结果”；这是排查方向，不是对当时行为的还原。只有用户提供的当时过程支持，才记“已确认”；否则写“待排查”，主因可待确认而不分类，或保留少量候选。步骤帮助决定练什么，不另设第七类错因。
6. **下次动作**：写清具体信号触发什么动作、从哪里找、什么证据足以确定，以及找不到或候选相持时怎样暂放和回查。优先给一句能带到考场的操作，如“题干问原因，读到事件后继续查为什么；原因完整对应后离开”。针对本题缺口，不写“更细心”等空话。

自测用于核实当前词义、改写或比较能力。看过解析后的复述、重做或新例测试不能还原当时错因；历史原因未明时继续保留待确认。

### 03 错因汇总

保留以下六类名称，只使用本篇有依据的类别，不强行给每题确定主因。

| 编号与名称 | 使用依据与边界 |
|---|---|
| **01 词句没读懂** | 关键本义或句子关系理解有误；错答本身不足以证明词汇不足。 |
| **02 换个说法没认出** | 两处表达各自能懂，却没认出对应；本义不懂时优先考虑01。 |
| **03 证据没找到** | 知道查找要求但没有找到有关句子；选错段、未高亮不能单独确认。 |
| **04 题目要求没查全** | 核对时遗漏必要条件；写明漏了哪项，不能仅凭错误候选缺条件就确认。 |
| **05 相似内容选混了** | 已比较相关候选，但错配主体、范围或关系；明确漏查条件时优先归04。 |
| **06 答案填写出错** | 有依据表明判断正确，仅拼写、单复数、字数或录入失误；不等同于所有“粗心”。 |

汇总只分“已确认”和“待排查”，列题号及针对动作。每题已确认仅记一个主因；其他有依据的影响可在正文补充，不作为待排查候选或重复统计。待排查候选可以分行列出，但同一题号不重复计题。证据不足可直接写“主因待确认”。时间压力单独记录，不凭空归因。

### 04 下一篇怎样做

保留 **读题、定位、确定答案、验证进步、保留做法** 五个提示项；围绕首要的一至两个动作组织，不给每个字段另加训练任务。方法应来自本篇具体考点与证据，不能把三份指南全文拼进报告。

用户强调做题速度时，在五个提示项前增加 **本篇提速路线**，按 [locating-and-timing.md](locating-and-timing.md) 写本篇先后安排、共用位置、省掉的操作、暂放与限时验证；数据用 `method.speed_plan`。表格解释整篇怎样执行，逐题表解释每题怎样省时，两者都不能替代错题分析。其他练习的超时反馈可注明为个人训练背景，不能填成本篇用时。

- **读题**：保留本次易漏的必要条件，不只盯题干后半句。
- **定位**：结合逐题速查，选择题干中有辨识度的入口和相关改写；共享已找到的段落线索，不每题从头重扫。不机械先填空或先通读，也不以顺序线索替代证据。
- **确定答案**：给出确定条件及暂放／回查条件；候选相持时保留候选和未核实条件，继续其他题，再有针对性地回查。考场不要求填复盘表、逐段起标题或逐句列主干。
- **验证进步**：在新材料记录限时内完成数、正确数／题数及用时；再单列超时补做。只在卡住题旁记一句耗时环节，复盘时检查动作是否执行。旧题重做、标记变少或牺牲准确率换快不能单独证明提高；不要求考场逐题计秒。
- **保留做法**：只保留有过程依据的方法；仅有答对结果时注明方法未核实，不据此推广，也不因另一题型出错而一并推翻。

用户以训练习惯为目的时，填写 `method.habits`，选一至两个最值得迁移的动作，用 **习惯名称、何时触发、立刻做什么、怎样算做到、记录什么** 表达。`pass_check` 要能通过新题作答痕迹或题组后简短说明核实：既检查动作是否执行，也检查证据是否正确；不能只凭最终选对推定执行过。`record` 只留必要信息，例如漏查条件的题号、无新证据却反复回读的题号，配合整组正确数和用时。旧题可演练动作，新材料才能检验迁移；不另铺每日打卡表或固定组数训练计划。

### 05 高亮修改

核对实际图像或用户明确提供的高亮文字记录，区分已标、未标和无法判断；按 **优先补标、取消或缩短、继续保留** 呈现，通常不超过一页。

- 每项注明位置、关联题号和具体词句。补标说明缺的条件；缩短给出保留内容；保留说明回查用途。优先处理错题；已答对题的补标为可选，不为完整而补涂全部答案。
- 区分临时定位词与最终答案证据。标记时机未知时，不把临时路标当作失败证据；取消或缩短主要依据是重复、辨识度低或妨碍回查，不能仅因本套题没问就全删。
- 保留决定答案的逻辑与限定，避免无任务目的的大段高亮；不机械规定数量或多色系统。“可取消”不等于句子无意义，也不要求初读时预知考点。
- 无带标记材料时写“未提供实际标记”，只能给建议，不编造“你已标／漏标／标多了”。

## 范围与交付核对

- 句意和逻辑解释服务答题，不扩展为长难句训练、仿写、词汇库或学习计划。
- 仅美化时保留已认可文字、判断与顺序；前后核对文本，不借排版删改。
- 核对五模块六字段、全文段落图范围、全题考点与定位覆盖、题干入口可用性、成绩及计时条件、引文、答案缺口与历史原因的分离、题型判定、可验证习惯及真实高亮；新增内容不删除错题解释，也不强行分析材料中不存在的题型。
