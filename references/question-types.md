# 按题型核对证据

只读取本篇出现的题型章节，不把本文件整段复制进报告。具体指令优先；下列判定方法服务复盘，不规定统一做题顺序。填空、段落信息匹配和判断题的训练方法结合用户提供的三份指南，来源与取舍见 [method-guides.md](method-guides.md)。这里的“考点”指本题实际需要核对的关系，不是官方频率排名。

题型与作答规则依据 [IELTS Academic Reading 官方说明](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)（核验于2026-09-29）；以下核对方法是本技能的教学建议。

逐题定位通用格式见 [locating-and-timing.md](locating-and-timing.md)。官方明确按文序的题型包括选择题、句尾匹配的句首、句子填空和简答；摘要类与图示可能不按文序。不要把某题型的顺序规则扩展到全部题目或不同题组。

## 段落信息匹配

找题目指定的事实或关系，具体例子也可成立；不以段落中心代替证据。两个候选都相关时逐项比较主体、动作、对象和限定，不用“更概括”排除。是否允许段落重复使用看题目指令，不假定题号对应原文顺序。

定位从题干对象与关系进入，如“某方案失败的原因”，扫读相应主题及因果表达，再读完整原因链。可以共用已建立的段落线索，不能每题只给正确段号，或要求每题从头精读全文。

**推荐思路**：本组先看指令与重复使用规则 → 把每题压缩为“信息类型＋对象＋关键限制” → 结合已有位置印象带题扫读 → 出现候选后读完整关系 → 核对后作答，保留未完成目标。初读一段可同时服务数题；不必背下所有题，也不要求考场为每段起标题。没有新证据的回读应转为“此处还缺什么条件”，再决定补读或暂放。

用题干信号明确要找什么，再写入每题具体考点：

| 信号 | 寻找与确认动作 | 不能混同 |
|---|---|---|
| reason／why | 找事件发生的原因，必要时跨句补齐 | 发生过事件不等于解释原因 |
| purpose／intended to；effect／result | 分开目的、措施与实际效果 | 打算改善不等于已经改善 |
| comparison／contrast | 对齐比较双方、维度和方向 | 同时出现两者不等于所需比较 |
| figures／statistics | 核对数字说明的对象、单位和状态 | 年份不自动是效果数据；文字量化也可能是数据 |
| example／description | 找指定现象的具体实例或描述 | 不必等到 example 原词；段落主旨不替代细节 |
| attitude／reaction | 核对谁对什么作出什么回应 | 对价格的态度不等于对口味的态度 |
| potential／problems／benefits | 核对可能或实际状态、影响对象及方向 | 过去时也可叙述当时预期；减少污染整体可表示好处 |

只检查题目实际限制。明确要求 two、both 或 different types 时落实数量或范围；不能机械数复数名词、句子或 and。预想改写只是检索帮助，最终证据仍须来自原文。

## 标题匹配

判断标题能否概括段落中心，区分支撑例子与统领观点；解释落选标题是覆盖过窄、过宽还是关系错配。首尾句可作入口，但不能替代必要上下文；同词或某个细节吻合不足以确定。标题不可重复使用。

题目指定段落就是检索范围。扫读首尾与转折处，核对中间内容是在举例、解释还是改变论点，再用一短句概括整段；定位表注明中心依据所在句及段落范围，不伪造唯一“答案句”。

## TRUE／FALSE／NOT GIVEN 与 YES／NO／NOT GIVEN

前者核对文本信息，后者核对作者观点或主张；引用他人的意见不自动等于作者赞同。TRUE／YES 需支持命题，FALSE／NO 需与命题冲突，NOT GIVEN 是缺少判定所需信息，不能凭常识补足。

复盘 NOT GIVEN 时写清核查了哪些相关段落或上下文、仍缺哪项关系或限定；不能因为一次没找到就断言未提及，也不能伪造原文否定句作证据。检查数量、时间、比较、因果与程度，不把“未支持”当“已反驳”。

从命题中的具体对象进入，保留量词、时间及比较对象，找到主题后核对整个命题。只在本题组已有可靠位置关系时借邻题缩小检索范围，不把判断题的顺序或两题之间的一句当作固定边界；NG 的主题位置不等于答案位置。

**推荐思路**：读成“对象＋主张＋关键限定” → 定位同一件事 → 读完整证据及必要上下文 → 判支持、冲突或信息不足 → 用一句短理由结束，进入下一题。确认一次是信息判断还是作者观点判断即可；不要求逐题重复解释题型。若只剩无依据的犹豫，保留具体疑点暂放，不能把暂放题直接判 NG。

按信号选择本题实际需要的核对，不给每题套完整清单：

- **否定范围**：not all 不等于 none，not always 不等于 never；“没有证据证明有效”不等于“证明无效”。
- **范围与程度**：some 本身不能反驳 all；若只知道一些人赞同、其余态度未交代，对“所有人赞同”应检查信息不足，只有明确例外才形成反证。may 不足以支持必然，也不能仅凭语气较弱就判 FALSE。
- **比较与新增关系**：A 比 B 快不能证明 A 在所有对象中最快；先后、相关不自动支持因果；目的不自动支持结果。写明具体缺了什么关系。
- **主体、时间与条件**：对齐动作角色、指代、阶段及成立条件；引用观点要确认归属。不同反应可能并存，“震惊”本身不能反驳“尴尬”。
- **多个必要部分**：对“A 且 B”，全部获得支持才是 TRUE；任一必要部分被明确反驳即可 FALSE；没有反证但缺必要信息才是 NOT GIVEN。不能一见某部分没提就直接选 NG。

复盘短理由须符合本题：TRUE 写完整主张的对应，FALSE 写同条件下的冲突，NG 写已核查范围和缺项。找到相同词只是定位；这三种结论的证据门槛才是判断训练重点。

## 填空与简答

先核对是原文取词还是选词，保留词数、数字及填写形式要求。证据需同时支持句意与空格位置；检查语法、单复数、拼写及词数，不能仅凭词性猜答案。

区分句子填空、简答与摘要／笔记／表格／流程图／图示：前两者可用题目顺序辅助；后几类不能一概假定顺序。摘要核对所在内容范围；流程和图示还要核对方向、步骤或部件对应。

从空格两侧的已知对象、动作或阶段进入，先找到相应关系再提取答案；不以空格答案词起步。流程与图示优先利用已有标签及连接关系，表格利用行列标题，不能只按空格编号向下找。

**推荐思路**：题组开始看要求与标题 → 把空格改述成一个明确问题 → 找相关位置 → 用空格两侧条件核对 → 按要求取词并填回检查。明确问题可以是“谁的什么”“什么使它能转动”“哪两项并列”，不必逐字翻译。先确认对象、动作或关系，再检查本题必要限制；语法预测用于筛选，不提前猜具体答案。

把以下检查转成该题的具体考点与证据对应：

| 题面或原文信号 | 核对动作 |
|---|---|
| of／with／by 等搭配 | 连同完整结构理解所属、被作用对象、工具、方式或截止时间，不能见介词就套一种意思 |
| 主动／被动、replaced／was replaced by | 还原谁对谁做了什么，防止动作角色互换 |
| and／both／as well as | 核对并列层级、已经给出的项和缺项，不能抄最近名词 |
| result in／result from、to／aim to | 对齐因果方向，并区分目的与实际结果 |
| local／main／only、before／after | 检查必要修饰、范围与阶段，不能只满足中心名词 |
| it／they／this、former／latter | 补读到指代清楚，答案不必与定位词在同一句 |
| 比较、数量变化 | 对齐比较双方及维度、变化量与最终值 |

改写可能跨短语或整句，例如 clay jars 本身可以表达“由 clay 制成”，不必出现 made of。空格左右都要有依据；一个候选只满足前半句时，还不能确认。取词要同时满足题意与字数，不一律只抄核心名词，也不一律带上修饰语。要求原文取词时保留所需原文形式；若填回不合，先查候选与取词范围，不擅自改词形迁就题干。

**省时重点**：要求每组核对一次，共用范围只定位一次；证据齐全且填写合规后推进。遇到生词只处理影响当前关系与判断的部分，关系不清仍须读懂，不能为快略过决定条件。

## 选择与多选

先核对选几个、问细节还是中心、是否含否定或比较。每个入选项都要有对应依据；针对用户误选项指出它在哪个条件上不成立，不把“文中出现过”当作答案。多选分别核验，不能因一个选项正确就连带确认另一个。

优先用题干对象找相关内容，读懂后按选项差异核对；选项中的独有名词也可能是干扰。细节题可借同题组已确认位置向后找，中心题核对其指定范围。多选中同一题组的答案字母或多个答题格不构成新的文序线索。

## 人物／特征匹配

用人名或特征定位后核对观点、行为或发现的归属，连同代词、转述和他人评价一起读；人名出现处不一定就是对应证据。选项能否重复依题目指令，不按人物出现顺序猜配对。

先用题面已给的人名／机构及其重复出现处建立简短索引，再匹配题干所说的观点或行为；表中给具体一次出现与归属依据。不能只找到第一个名字就停止核对。

## 句尾匹配

把句首与候选句尾拼成完整命题，核对语义关系和原文依据；语法通顺只是必要检查，不能代替证据。句首顺序可辅助定位，句尾列表顺序不代表答案顺序。

从句首的已知对象和动作定位，核对原文接下来补充的是原因、结果还是条件，再选句尾；不要先认定某个句尾正确，再拿其中词语倒推搜索入口。
